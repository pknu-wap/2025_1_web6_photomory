# 📸 Photomory

> 친구들과 사진을 공유하고, 추억을 기록할 수 있는 **그룹 기반 앨범 웹 서비스**

🔗 [프론트엔드 배포 링크 바로가기](https://photomory.netlify.app/)  
[![Netlify Status](https://api.netlify.com/api/v1/badges/b56018c7-a139-418e-96d6-13c2d57de3fd/deploy-status)](https://app.netlify.com/projects/photomory/deploys)

---

## 🧩 주요 기능

| 기능 | 설명 |
|------|------|
| ✅ 그룹 생성 | 친구들과 함께 앨범을 꾸밀 수 있는 그룹을 생성 |
| ✅ 앨범 추가 | 그룹 내에서 앨범 생성 및 사진 업로드 |
| ✅ 사진 업로드 | 제목, 촬영일자 입력 후 앨범에 등록 |
| ✅ 태그 필터링 | 태그 기반으로 앨범 필터링 |
| ✅ 캘린더 보기 | 날짜별 업로드 사진을 시각화하여 표시 |
| 🛠️ 알림 기능 | SSE 기반 실시간 알림 수신 (추가 예정) |
